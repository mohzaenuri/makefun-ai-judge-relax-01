A Minute That Belongs to No One is a small deterministic program that writes a short guided pause for whoever reads it. It starts with slow breathing — in for four counts, out for six — letting the shoulders drop a little further with each breath, and then paints a quiet picture: a porch in the late afternoon, warm wood underfoot, bees humming somewhere beyond the garden fence, sunlight moving so slowly across the floor that you can watch it and still miss it, and a cold glass sweating quietly beside you. There is nothing to finish and nothing to answer; the day does its own work without you, and when you are ready, the world is still there, a little softer than you left it.

## Run it

```sh
python3 main.py
```

The program writes `entry.txt` into the directory named by `MAKEFUN_OUTPUT_DIR`, or `/output` when that variable is unset.
